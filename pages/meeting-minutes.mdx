# Meeting Minutes

Meeting Minutes has expanded from a basic recorder into a full meeting evidence and synthesis workflow. You can start from live capture, import existing files, link meetings to calendar events, and generate reusable outputs with ACP-powered synthesis.

## What the dashboard gives you

- `Active Meeting` for sessions still collecting evidence or waiting on wrap-up
- `Upcoming Meetings` for calendar-linked or manually scheduled meetings
- `Recent Outputs` for generated drafts such as minutes, summaries, action items, or follow-ups
- `Readiness` checks so you can see whether recording and synthesis prerequisites are available

## Live capture workflow

For live meetings, RealTimeX can:

- record and store session audio
- stream or process transcription with the configured runtime
- keep meeting evidence inside the thread
- generate a first draft once the session is ready for synthesis

The current settings surface focuses on transcription runtime, local Whisper model management, and synthesis defaults for new meetings.

## Import existing meeting records

You can also start from existing evidence instead of a live recording.

Supported inputs include:

- audio files
- video files
- transcripts
- screenshots
- PDFs
- other supporting meeting documents

Imported files can either create a new meeting or be added to an existing one before synthesis runs.

## Synthesis and reusable outputs

Meeting Minutes can generate multiple output styles from the same source meeting:

- minutes
- summary
- action items
- decisions
- follow-up

Defaults are managed in `Settings > Meeting Minutes`, where you can set:

- the preferred transcription provider and runtime behavior
- the default storage location for meeting working data
- the ACP synthesis agent used for first drafts
- an optional model override
- watcher cooldown behavior
- reusable synthesis templates

For the full setup guide, see [Meeting Minutes Settings](/meeting-minutes-settings).

## Calendar-linked meetings

Meeting Minutes now works better with Calendar workflows:

- upcoming meetings can appear directly in the dashboard
- meeting context can arrive from calendar-linked events
- calendar planning and meeting capture can stay in one workflow instead of two disconnected tools

## After the meeting

Once a meeting finishes, RealTimeX keeps the meeting thread and generated outputs together so you can:

- reopen the original meeting context
- regenerate or compare outputs
- review recent drafts from the dashboard
- continue asking AI questions against the meeting evidence

## Recommended setup

1. Configure Meeting Minutes defaults in `Settings > Meeting Minutes`.
2. Confirm your transcription runtime and local model availability.
3. Choose whether you want to start from live capture or imported records.
4. If you already use Calendar, connect it so upcoming meetings can flow into this workspace more cleanly.

## Tips

- Use imported records when a live meeting has already happened elsewhere.
- Treat templates as the fastest way to standardize output across recurring meeting types.
- Pair Meeting Minutes with [Calendar](/calendar) when you want scheduling, prep, capture, and follow-up to stay connected.
