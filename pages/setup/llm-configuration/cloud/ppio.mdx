# PPIO

`PPIO` lets RealTimeX connect to PPIO-hosted models through a standard API-key workflow.

Open it from `Settings > AI Providers > LLM`, then choose `PPIO`.

## What you need

Before RealTimeX can use PPIO:

- you need a valid PPIO API key
- the RealTimeX instance must be able to reach the PPIO service

## Current setup flow

1. Open `Settings > AI Providers > LLM`.
2. Choose `PPIO`.
3. Paste your API key.
4. Select the model you want to use from the grouped catalog.
5. Save the provider settings.
6. Test a normal chat.

<Callout type="info" emoji="💡">
  The current UI groups PPIO models by organization to make larger model catalogs easier to navigate.
</Callout>
