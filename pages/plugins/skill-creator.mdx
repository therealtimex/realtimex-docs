# Skill Creator

`Skill Creator` is a built-in plugin that is enabled by default.

It gives agents a structured workflow for creating, evaluating, benchmarking, and improving reusable skills.

## What it adds

- skill authoring help
- automated assessment and grading workflows
- analysis for comparing or refining skill behavior

## Where it matters

This plugin matters when a user wants to:

- create a new skill from scratch
- improve an existing skill
- run evaluations on a skill
- benchmark multiple versions of a skill

You usually do not open a separate `Skill Creator` screen. The capability appears when an agent is asked to help with skill-development work.

## Configuration

`Skill Creator` does not expose a separate plugin settings form in current builds.

For most users, leaving it enabled is the right default.

## What happens if you disable it

If you disable `Skill Creator`, agents lose the built-in workflow for structured skill evaluation and iterative skill improvement.

General agent help may still work, but skill-specific authoring and grading assistance becomes weaker.

## Troubleshooting

- If a skill-development workflow should be available but is not, confirm `Skill Creator` is enabled.
- Reload the plugin after changes to the broader plugin environment.
