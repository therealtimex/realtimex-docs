# RealTimeX v1.1.268

Released 2026-07-17.

## Changed

- **Calendar connections on desktop**: Calendar CLI connections are now active by default on capable desktop runtimes. Calendar connections are managed from the Calendar modal; the legacy BYOK settings page and admin credential endpoints remain available only when the desktop flag is rolled back or the CLI capability is unavailable, preserving hosted behavior.
