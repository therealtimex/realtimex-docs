# Upcoming changes

<Callout type="info">
These are the current notes for the next stable release, covering changes since v1.2.235. They're updated as work is merged, so a development build may not include every change listed here. When the release ships, they become its notes.
</Callout>

## Fixed

- **RealTimeX starts normally after it was opened as administrator**: if RealTimeX had been opened as administrator and was then opened normally, the normal copy couldn't stop the old one's background processes. The loading screen waited and ended with "Max reconnection attempts reached". The normal copy now stops them and starts as usual. If Windows still refuses (for example, the old copy runs in another Windows session), RealTimeX says at once that it couldn't stop a background process and how to recover, instead of waiting. It still never starts a second copy of its server next to the old one. Startup error cards also no longer run off the side of the window when the device ID is long.
- **BizOps CRM steps use the `gog` on your PATH first**: BizOps CRM and briefing steps always ran Homebrew's `gog` (`/opt/homebrew/bin/gog`) when it was installed, even if you had another `gog` earlier on your PATH. They now use the first `gog` on the PATH they run with, and fall back to Homebrew's only when none is found there.
