# Private managed RealTimeX

RealTimeX Cloud is the managed collaboration path for teams that want shared workspaces, centralized administration, and operational rollout without running the infrastructure themselves.

The RealTimeX, Inc team offers **isolated** and **private** instances of RealTimeX that you can use to evaluate, deploy, and scale RealTimeX for team use.

Each instance is hosted on an isolated cloud instance that is automatically updated and managed by the RealTimeX, Inc core team. Your data and resources are not shared with any other customers who are using our managed service.

## Best for

- shared workspaces and multi-user access
- centralized credentials, admin setup, and operator visibility
- channels, public exposure, and broader organizational rollout
- buyers who want managed infrastructure instead of self-hosting

## Why teams choose Cloud

- **Shared workspaces:** Give multiple users access to the same knowledge, threads, and operational surfaces.
- **Centralized administration:** Manage users, security, credentials, channels, and workspace access in one place.
- **Managed operations:** Let the RealTimeX team handle updates and hosted infrastructure for the instance.
- **Same product story, broader rollout:** Use the same wider platform surface - chat, retrieval, agents, channels, meetings, plugins, and governance - in a collaboration-first deployment.

## Desktop vs Cloud

- Choose [Desktop](/installation-desktop/overview) when the first goal is a fast operator-led pilot with local context, local models, or machine-local execution.
- Choose Cloud when the first goal is shared collaboration, centralized control, or organization-wide access.
- Use a hybrid story when you want shared workflows but still want some models, files, or execution paths to stay local.

## Common rollout path

Many teams start with Desktop to prove one high-value workflow, then move to Cloud or a hybrid setup once they want broader access, stronger administration, or customer-facing exposure.

If you already know you need shared workspaces, channels, and managed administration from day one, Cloud is usually the better starting point.
