# Personal Notes

Personal Notes is a dedicated file and note workspace for your own research, drafts, and long-lived reference material. It combines a file manager, note editor, assistant, preview tools, and optional note search in one place.

## Where to find it

- Open `Personal Notes` from the main sidebar.

## What you can do

- Create notes and folders
- Upload source documents
- Preview and edit files in place
- Ask the built-in `Notes Assistant` about your content
- Read supported notes and documents aloud with text-to-speech

## Wiki projects

Personal Notes can scaffold structured wiki projects for deeper research or operating manuals.

Creating `New Wiki Project` gives you a starter folder with:

- `WIKI.md`
- `raw/`
- `index.md`
- `log.md`

This makes it easier to keep source material, structured summaries, and project history together.

## Note search

`Note Search Settings` controls whether RealTimeX searches your notes and injects relevant note content into assistant context.

You can tune:

- whether note search is enabled
- search mode
- max results
- timeout behavior

This is useful when your notes are large enough that you want retrieval instead of opening files manually.

## When to use Personal Notes

Personal Notes works well for:

- personal research
- long-lived operating notes
- project journals
- small private knowledge bases
- wiki-style reference sets you want to grow over time

## Helpful connections

- Use [Working Directories](/agent-runtime) if you want agents to write directly into a Personal Notes wiki project.
- Use [Knowledge Manager](/knowledge-manager) when you want curated agent reference collections in a separate settings surface.

## Tips

- Keep wiki project names short and stable so linked workflows remain easy to follow.
- Use uploads for source material, then summarize or reorganize it into markdown notes.
- Enable note search when you want the assistant to retrieve from your notes automatically instead of relying on manual browsing.
