# RealTimeX Documentation

RealTimeX is the AI work operating system for teams that need more than chat.

It brings together workspace chat, retrieval, meetings, agent runtimes, channels, plugins, and deployment choice so teams can move from context to execution in one product.

Use these docs to understand the product story first, then drill into setup, runtime, and feature details.

## What RealTimeX Brings Together

- Workspace chat, retrieval, and knowledge so documents and context stay close to the work.
- Agent runtimes, MCP, browser workflows, local apps, and scheduled Ambient follow-up for execution.
- Meetings, calendar context, goals, and thread tracking so work does not stop at one prompt.
- Channels, plugins, and marketplace assets so AI can live where teams already operate.
- Desktop, cloud, and hybrid deployment choices with operator controls around credentials, approvals, and access.
